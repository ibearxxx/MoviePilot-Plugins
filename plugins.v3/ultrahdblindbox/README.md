# UltraHD幸运盲盒

每天自动抽 UltraHD PT 站的「幸运盲盒」。站点规则：**一天最多 30 次，第一次免费**，
之后每次消耗 3000 魔力值。

插件默认只抽免费的那 1 次；要付费抽必须自己把「每日抽取次数」改大（1–30）。

## 配置

| 项 | 默认 | 说明 |
|---|---|---|
| 启用插件 | 关 | — |
| 发送通知 | 开 | 跑完发一条汇总 |
| 站点 | UltraHD | MoviePilot「站点管理」添加站点 |
| 每日抽取次数 | 1 | 1–30 |
| 执行周期（cron） | `30 8 * * *` | 默认每天 08:30 |

## 抽取规则

一次运行的做法是：先读盒子状态（还剩几次免费、今天还能抽几次、当前魔力值），
再按下面的规则决定抽几次，抽完发**一条**汇总。

| 情况 | 行为 |
|---|---|
| 免费额度还在 | 按配置抽 N 次：第 1 次免费，其余付费 |
| 免费额度已被手动用掉，N=1 | **跳过，什么都不抽** |
| 免费额度已被手动用掉，N>1 | 抽 N-1 次付费，把免费那格让出来 |
| 当天计划次数已跑满 | 跳过——**同一天不重复抽** |

抽取规则：

1. **同一天不重复抽。** 每抽一次就落盘进度，cron 抖动或手动再点「立即运行」都不会多抽。
2. **失败不自动重试。** 抽奖是付费动作，重试等于重复扣魔力值；失败如实报，由人决定要不要再来。
3. **中途失败即停。** 第 N 次失败就收工，不会把剩下的次数抽完再报。

## 通知

一轮一条，形状固定：

```
盲盒：免费 1 次 + 付费 3 次，消耗 9,000 魔力值，获得 15GB 上传 ×1、10 魔力值 ×3
```

失败时同一行末尾补上原因：`…；第 2 次失败：<站点原文>`。

## 文件

```
ultrahdblindbox/
├── __init__.py    插件主类：配置 / 表单 / 详情页 / 调度 / 同日防重 / 记录 / 通知
└── blindbox.py    站点接口层：唯一跟站点说话的地方（会话、请求、回包解析）
```

接口层与主逻辑只靠三个东西耦合：`Client.state()` 返回盒子状态、`Client.draw(free)`
返回一次抽取结果、`BoxState` / `DrawResult` 两个数据结构。换站点协议时只动 `blindbox.py`。
